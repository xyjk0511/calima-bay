A 3D WebGL sun-soaked coastal open-world crime action game set in **Calima Bay**, built with Three.js and procedural Web Audio. Play as **Rico Vega** alongside crewmates **Nadia Cruz** and **Tito Morales** across six distinct waterfront and downtown districts, eight multi-stage story operations, a 5-star **CBPD** tactical dispatch system with **CALIMA-1** aerial searchlight pursuit, vehicle tuning at **Morales Customs**, and an underground armory.

## Features

- **Six Seamless 3D Districts**: Palma Strip, Solstice Downtown, Puerto Azul Docks, Mirador Heights, Barrio Coral, and the Cayo Brisa Causeway over shimmering turquoise waters.
- **Eight Multi-Stage Story Operations**: From street boosts and boardwalk shakedowns to harbor contraband raids, neon drift circuits, vault heists, and the Sunset Reckoning finale.
- **Arcade Driving & Carjacking**: Nine distinct vehicle classes with handbrake drifting (`Space`), nitro boost (`Shift`), damage/explosions, and instant enter/exit/hijack (`F`).
- **5-Star CBPD Tactical Dispatch**: Escalating patrol cruisers, PIT pursuits, highway roadblocks, SWAT Enforcers, and the `CALIMA-1` helicopter with live tracking spotlight cones.
- **Six-Weapon Arsenal & Combat**: Street Baton, 9mm Tactical Pistol, Micro-SMG, Combat Shotgun, Carbine Rifle, and Frag Grenades with weapon wheel (`Q`), tracer fire, and destructible vehicles.
- **Living City & Crew Progression**: Autonomous traffic, reacting pedestrians, rival Vargas Cartel patrols, 8 stunt jump ramps, Morales Customs upgrades, 4 procedural FM radio stations (`R`), dynamic time-of-day (`T`), and 3-slot career saves (`F5` / `Tab`).

## Controls

| Key | Action |
| --- | --- |
| `W A S D` / Arrows | Move on foot / Drive |
| `Mouse` + `Left Click` | Look / Aim & Fire |
| `F` | Enter / Exit / Hijack vehicle |
| `Space` | Handbrake Drift (driving) / Jump (on foot) |
| `Shift` | Nitro Boost (driving) / Sprint (on foot) |
| `1`–`6` or `Q` | Switch Weapon / Weapon Wheel |
| `E` | Open Morales Customs Garage / Underground Armory |
| `C` | Trigger Crew Ability (Radio Jammer / Repair / Bribe) |
| `R` | Cycle FM Radio Stations |
| `T` | Cycle Time of Day (Golden Sunset / Neon Dusk / Coastal Day / Twilight) |
| `Tab` / `Esc` | City Atlas, Career Stats & Save Slots |
| `F5` | Quick Save |

## Running Locally

```bash
node serve.ts --port 8080
```

Then open `http://127.0.0.1:8080/` in a modern browser.
